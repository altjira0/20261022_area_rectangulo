
# Cálculo área rectángulo y círculo.

Este proyecto calcula el área de un círculo y de un rectángulo, dejando que el usuario meta el lado del rectángulo y el radio del círculo, en las unidades que quiera. 

## Libraries 
Usamos la libreria math para usar todos los decimales del número pi. 
## Installation
Abra Visual Code Studio y ejecute en el terminal:

```bash
  python .\area.py   
```
    
## How to use it
Ejecute el programa e introduzca el valor del lado del rectángulo; le dirá el área del rectángulo.
Luego introduzca el valor del radio, le dirá el área del círculo, redondeado a 2 decimales.
